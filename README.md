# Penguin Mod
Welcome to my Minecraft Penguin Mod! This mod introduces adorable penguins, unique behaviors, and special abilities that will enhance your gameplay experience. 

## Features
Penguins: Discover penguins that spawn in snowy and icy biomes.
Custom Animations: Realistic and fun animations for penguin movement, swimming, and interactions.
Unique Status Effect - Penguin's Grace: This custom effect gives you increased movement speed in boats.

## Installation
Download the Penguin Mod: Get the latest version from releases.
Move to Mods Folder: Place the downloaded .jar file into your mods folder in the Minecraft directory.
Launch Minecraft: Start Minecraft from your launcher and enjoy your adventure with penguins!
